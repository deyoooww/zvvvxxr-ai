# ZVVVXXR AI

Premium mobile-first AI companion application with Zee, your personal AI assistant.

## Features

- 💬 **AI Chat** - Chat with Zee, your AI companion
- 📚 **Study AI** - Learn with study materials and flashcards
- 🎓 **Homework Help** - Get help with homework and assignments
- 🖼️ **Image AI** - Analyze and understand images
- 📄 **Document AI** - Process and extract information from documents
- 💻 **Coding AI** - Get help with programming and code
- 🌐 **Website Builder** - Create websites with AI assistance
- 🛠️ **Utility Tools** - Calculators, converters, and more
- 💾 **Persistent Chat History** - Your conversations are saved
- ⚙️ **Customizable AI** - Customize Zee's name, photo, and appearance

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Vite
- IndexedDB (Dexie)
- Lucide React Icons
- CSS Modules
